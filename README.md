# TypeScript Types and Generics

A set of small TypeScript scripts covering basic types and generics.

## Contents

### `src/baseTypes/`

Nine exercises applying TypeScript's basic types (`number`, `string`, `boolean`, `null`, `undefined`, `unknown`, `any`, tuples, enums, and union types) to plain JavaScript code, including building a custom type from an existing object shape.

### `src/generic/`

Eight exercises using generic types and generic functions, including typing a `Promise` return value and other generic utility patterns.

## Stack

- TypeScript 5

## Usage

```bash
npm install
npx tsc
```
